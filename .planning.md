# Itens para versões futuras

## 1. Orçamentos

```txt
budgets
budget_categories
```

### Objetivo

Permitir que o usuário planeje quanto pretende gastar por período e por categoria.

### Exemplos

- orçamento mensal;
- orçamento quinzenal;
- orçamento anual;
- orçamento por ano fiscal;
- limite planejado por categoria.

### Funcionalidades futuras

- definir valor planejado por categoria;
- comparar planejado vs gasto real;
- alertar quando uma categoria estiver perto do limite;
- permitir orçamento mensal automático;
- permitir orçamento customizado por período.

---

## 2. Metas financeiras

```txt
goals
goal_contributions
```

### Objetivo

Permitir que o usuário acompanhe objetivos financeiros.

### Exemplos

- reserva de emergência;
- viagem;
- compra de um carro;
- reforma da casa;
- quitar uma dívida.

### Funcionalidades futuras

- definir valor objetivo;
- definir prazo;
- registrar contribuições;
- calcular progresso;
- vincular contribuições a transações;
- exibir percentual concluído.

---

## 3. Lista de compras

```txt
shopping_lists
shopping_list_items
```

### Objetivo

Permitir que o usuário crie listas de compra, principalmente para mercado, mas também para outros usos.

### Exemplos

- mercado;
- farmácia;
- material escolar;
- churrasco;
- presentes;
- itens para casa.

### Funcionalidades futuras

- criar lista planejada;
- adicionar itens;
- marcar itens como comprados;
- informar quantidade;
- informar preço estimado;
- reutilizar listas anteriores.

---

## 4. Compras detalhadas

```txt
purchases
purchase_items
```

### Objetivo

Registrar a compra realizada com detalhes dos itens comprados.

### Exemplos

- compra de mercado;
- compra de farmácia;
- compra de materiais;
- compra de itens domésticos.

### Funcionalidades futuras

- transformar lista em compra realizada;
- comparar preço estimado vs preço real;
- registrar itens extras;
- vincular compra a uma transação ou compra no cartão;
- acompanhar histórico de preços por item;
- analisar gastos por produto.

---

# Estrutura deixada para depois

```txt
budgets
budget_categories

goals
goal_contributions

shopping_lists
shopping_list_items

purchases
purchase_items
```

# Motivo

Essas funcionalidades são úteis, mas não são necessárias para a primeira versão.

A V1 deve focar em:

```txt
contas
transações
transferências
recorrências
cartão de crédito
faturas
parcelamentos
pagamento de fatura
```

Assim o app começa simples, prático e funcional para controle financeiro diário.
